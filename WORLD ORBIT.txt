# WORLD ORBIT

## 24/7 Interactive Geopolitical War Simulation & YouTube Live Entertainment Platform

**Product Type:** Real-time persistent simulation + livestream visual engine
**Primary Format:** 9:16 vertical canvas optimized for YouTube Live/Shorts-style viewing
**Primary Experience:** Viewers watch autonomous countries compete, ally, trade, evolve, and enter conflicts in a continuously running simulated world.
**Primary Goal:** Maximize viewer retention through anticipation, emergent stories, visual motion, rare events, and audience participation.
**Status:** Product Definition
**Version:** 1.0
**Date:** August 2026

---

# 1. Executive Summary

WORLD ORBIT is a continuously running geopolitical simulation designed specifically to generate compelling 24/7 vertical livestream content.

The core visual is a collection of national flags orbiting a glowing central world. Countries behave as autonomous entities with different levels of power, economy, diplomacy, technology, military capability, alliances, rivalries, and strategic personalities.

The system continuously generates:

**Diplomacy → Tension → Crisis → War → Battles → Territory Changes → Recovery → Alliances → New Conflicts**

The simulation does not simply show random battles. It creates **persistent stories**.

A viewer joining at any moment should immediately understand:

1. Who is powerful?
2. Who is fighting?
3. What is about to happen?
4. Why should I keep watching?

The product should feel like a combination of:

* A strategy game
* A geopolitical visualization
* A live sports broadcast
* An autonomous simulation
* A mystery generator
* A spectator game
* A 24/7 television channel

---

# 2. Product Vision

## Vision

Create a virtual world that is **always alive**.

The viewer should feel:

> "Something is happening right now."

and:

> "I wonder what happens next."

The world should continue evolving whether there are:

* 0 viewers
* 10 viewers
* 1,000 viewers
* 100,000 viewers

The simulation itself is the content-generation engine.

WORLD ORBIT should follow five principles.

## 3.1 Always Moving

The screen should never feel frozen.

Flags orbit.

Energy pulses.

Connections move.

Events appear.

Battlefields evolve.

Statistics change.

A viewer joining for five seconds should understand the current situation.

Visual storytelling comes first.

A war should affect:

* Economy
* Population

* Alliances

## 3.5 Rare Events Matter

Most events should be normal.

Occasionally something extraordinary should happen.

The viewer should feel:

> "I can't leave because something huge might happen."

# 10. Orbital Physics

Flags should not rotate mechanically.

Each flag has:

* Orbital velocity
* Angular acceleration
* Bounce factor
* Attraction force
* Repulsion force
* Orbit radius
* Vertical offset
* Random drift
* Interaction force

Movement should feel organic.

### Normal State

Smooth movement.

### Tension State

Increased movement.

### Crisis State

Orbit paths converge.

### War State

Aggressive motion.

### Defeat

Movement slows and flag becomes visually weaker.

# 57. Simulation Tick

Avoid running every expensive calculation every frame.

Separate:

### Render Tick

30–60 FPS.

### Simulation Tick

1–10 updates per second.

### Strategic Tick

Every 5–30 seconds.

### Major Event Evaluation

Every 10–60 seconds.

### Economic Update

Every few seconds/minutes.

This dramatically reduces CPU usage.

```text
AI Decision

Decision Validator
↓
Simulation Rules
↓
Accepted Action

World State
```

# 100. Product Principle

The most important requirement in the entire PRD is:

> **Never optimize for constant action. Optimize for anticipation.**

If something explosive happens every five seconds, nothing feels special.

Instead:

**calm → tension → anticipation → event → consequence → calm → tension**

That rhythm allows WORLD ORBIT to remain watchable for hours while still producing moments spectacular enough to become viral clips.

The ultimate goal is to build not merely a simulation, but a **persistent automated entertainment engine capable of generating an endless stream of geopolitical stories.**
